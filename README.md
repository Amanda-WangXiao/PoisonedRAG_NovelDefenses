# PoisonedRAG with Novel Defenses  

## About this Repo  
Based on the PoisonedRAG framework under a black-box setting, this repository designs two novel defense mechanisms:  
1. Security Score Defense  
2. Semantic Consistency Verification Defense  

[Security Score Defense](https://github.com/Amanda-WangXiao/PoisonedRAG_NovelDefenses/blob/noveldefenses/pics/ASR_Threshold_NQ.pdf)
[Semantic Consistency Verification Defense](https://github.com/Amanda-WangXiao/PoisonedRAG_NovelDefenses/blob/noveldefenses/pics/ASR_Semantic_Consistency_NQ.pdf)
